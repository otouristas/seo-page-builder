## Search Console property-first onboarding — 2026-09-09

New accounts with no projects now enter a property-first onboarding flow after account authentication. RankSushi starts a separate Google Search Console OAuth request for the read-only `webmasters.readonly` scope, lists the verified properties returned by Google, and creates one project from the selected property. The selected property, normalized website URL, project details and encrypted refresh credentials are saved together; an initial sync is queued when the plan and Inngest setup allow it. Existing URL-first projects retain Settings → Connections for reconnecting or choosing a property later.

The onboarding handoff uses short-lived, encrypted, HTTP-only cookies so credentials never reach the browser client or query string. State mismatch, expiry, denied consent, revoked access and duplicate callback paths recover to the onboarding screen. The implementation is in `src/app/api/gsc/onboarding/`, `src/lib/server/gsc-onboarding.ts`, `src/lib/integrations/gsc.ts` and `src/components/auth.tsx`.
